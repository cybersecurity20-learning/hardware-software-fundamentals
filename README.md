# Hardware and Software Fundamentals

## Project Overview

This repository documents my learning journey in Computer Hardware and Software through theoretical studies and practical exercises.

The project covers essential computer components, operating systems, storage devices, memory, and basic troubleshooting concepts.

## Learning Objectives

- Understand the main components of a computer.
- Learn the differences between hardware and software.
- Identify computer memory and storage technologies.
- Understand operating systems and their functions.
- Explore basic computer maintenance and troubleshooting.

## Computer Hardware

Computer hardware refers to the physical components of a computer system.

Main topics:

- CPU (Central Processing Unit).
- RAM (Random Access Memory).
- Motherboard.
- Power Supply Unit (PSU).
- Storage Devices (HDD and SSD).
- Network Adapters.

## Computer Software

Software refers to the programs and instructions that allow a computer to perform different tasks.

Main topics:

- Operating Systems.
- Applications.
- Device Drivers.
- System Software.
- Utility Programs.

## Memory and Storage

Understanding the differences between computer memory and storage technologies.

Topics include:

- RAM.
- SSD.
- HDD.
- SATA.
- M.2.
- External Storage Devices.

## Operating Systems

Learning the basic functions of operating systems, including resource management, file management, and hardware communication.

## Basic Troubleshooting

Studying common computer problems and basic troubleshooting concepts.

## Learning Outcomes

Developing foundational knowledge of computer hardware, software, operating systems, and basic technical support.
